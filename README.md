# ecommerce-analytics-bigquery
rojeto de análise dos dados da Google Merchandise Store, desenvolvido com SQL, Google BigQuery e Looker Studio.

# Objetivo

Analisar o desempenho da loja e identificar padrões relacionados a receita, pedidos, produtos, dispositivos, canais de aquisição e comportamento dos clientes.

# Análises realizadas

Indicadores de receita, pedidos, sessões e visitantes

Receita por dispositivo

Receita por categoria de produto

Visualizações de produtos versus vendas

Receita por canal de aquisição

Ticket médio por país

Carrinhos abandonados de alta intenção

# Tecnologias utilizadas

SQL

Google BigQuery

Looker Studio

Google Analytics Sample Dataset

# Dashboard

[Visualizar dashboard no Looker Studio](https://datastudio.google.com/reporting/ccd9cd7c-88be-47e7-b7f7-21b461e9e052)

# Principais resultados

O conjunto analisado apresentou aproximadamente US$ 4,58 milhões em receita, 23,9 mil pedidos e 524 mil sessões entre agosto de 2016 e agosto de 2017.
